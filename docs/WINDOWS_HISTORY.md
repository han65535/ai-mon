# Windows 주간·월간 사용 이력

Windows 앱의 **사용 기록** 버튼 또는 트레이 메뉴에서 주별·월별 이력을 열고, 모델·확인 가능한 출처별 토큰과 기간 합계를 볼 수 있다. 주는 PC의 로컬 시간대에서 월요일에 시작한다. CSV는 UTF-8 BOM을 포함하며 현재 선택한 기간 단위의 집계 행을 저장한다. 캐시 읽기 토큰은 입력에 포함된다.

이력은 `%LOCALAPPDATA%\AI Mon\history.sqlite3`에 저장하며 설치 제거 후에도 남는다. Claude 메시지에 기록된 모델과 Codex 작업 문맥의 모델을 사용한다. 모델 전환을 가로지르는 누적값, 출처를 확인할 수 없는 세션은 각각 **모델 알 수 없음**, **출처 알 수 없음**으로 분류한다. Codex의 `sessions` 옆 `archived_sessions`도 읽는다. 파일이 다른 경로에 있는 경우 설정에서 로그 폴더를 지정할 수 있다.

이 PC의 설정된 로컬 기록만 수집한다. 다른 기기·웹·원격 서버·WSL이나 다른 설정 디렉터리의 기록이 자동으로 모두 포함되는 것은 아니다. 기능을 사용하기 전에 이미 삭제된 로그는 복원할 수 없으며, 이전 7일 상태 캐시에만 남은 데이터는 새 이력 DB로 자동 이전하지 않는다. 한 번 수집한 이력은 원본 로그와 앱을 제거한 뒤에도 남는다. 파일이 교체되거나 수정되어 기존 누적값을 정확히 보정할 수 없는 경우 이력 창에서 주의 상태를 표시한다.

모델·출처·토큰과 중복 제거 및 파일 읽기 위치에 필요한 식별자를 저장한다. 프롬프트·응답 본문과 인증 정보는 이력에 저장하지 않는다. 이력은 자동으로 삭제되지 않으므로 시간이 지나면 디스크 사용량이 늘 수 있다. 이력 파일이 남아 있으면 앱을 재설치해도 다시 사용할 수 있다.

Windows 10/11의 시스템 `winsqlite3.dll`을 시스템 폴더에서만 찾아 사용한다. 앱에 SQLite DLL을 동봉하지 않는다. 시스템 라이브러리를 열 수 없거나 필요한 함수가 없으면 다른 앱 기능은 계속 동작하고 이력 창에 읽기 실패가 표시된다. [Microsoft 문서](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/custom-versions)는 `winsqlite3.dll`을 Windows 10 시스템 SQLite로 설명한다.

## 검증

- 기존 Windows 테스트와 이력 테스트를 결합했다. 한글 경로, 모델 전환, VS Code 출처, 주별·월별 집계, 보관 파일 중복 제거, 수정, 재시작, 원본 삭제 뒤 보존과 CSV 내용·수식 방지를 검사한다.
- `scripts/test-history-ui.ps1`은 테스트 빌드의 별도 UI 검사다. 주·월 선택과 한국어·영어 전환을 확인한다. `scripts/test.ps1`은 코어 테스트를 실행한다.
- Linux 호스트의 Wine 환경에서 SQLite 3.23.1로 빌드한 **시험용 대체 DLL**을 Wine 시스템 디렉터리에 넣고 Windows 코어 테스트, 이력 UI 테스트, 앱 스모크 테스트를 통과했다. 실제 Microsoft `winsqlite3.dll`이나 Windows 10/11 실기기 실행을 뜻하지 않는다.
- LLVM-MinGW 20260908 UCRT 교차 빌드에서 실행 파일은 1,000,000바이트 미만이며 필수 PE 보호와 시스템 DLL 의존성을 확인했다.
- 로그인된 Claude의 실제 VS Code 출처 분류, Windows 실기기·DPI·실제 트레이 및 파일 저장 대화상자는 미검증이다. 해당 정보가 없으면 출처를 추정하지 않는다.

## 로컬 개발 빌드

`out/Release/ai-mon.exe`는 Windows x64용 포터블 빌드 0.4.1이다. 별도 설치 없이 실행할 수 있다. 설치형 MSI는 이 환경에서 생성하거나 검증하지 않았다. 배포 여부는 GitHub 릴리스 페이지에서 확인한다.

- 실행 파일: 559,616바이트
- SHA-256: `4e0a92278ac845d0bf3483330d14bab3a5ffd2e7f7af4ac0340d5042f0ebd36b`
- LLVM-MinGW 20260908 UCRT로 교차 빌드. x64, ASLR, DEP, CFG 및 시스템 DLL만 사용함을 확인했다.
- Wine에서 SQLite 3.23.1 대체 DLL을 사용해 기존 코어 테스트 308개, 이력 테스트, 이력 창의 주별·월별 및 한국어·영어 전환 테스트, 앱 시작 스모크 테스트를 통과했다. 이력 테스트는 기존 테스트 실행에 포함된다. 시스템 SQLite DLL이 없는 경우에도 앱의 나머지 기능이 시작되는 것을 별도로 확인했다.
- 공유 이력 코드 변경 후 Linux 코어, 이력, X11·Wayland UI 회귀 검사도 통과했다.
