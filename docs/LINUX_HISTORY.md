# Linux 주간·월간 사용 이력

상세 창의 **주간·월간 기록**에서 주별 또는 월별로 전환한다. 주는 로컬 시간대 기준 월요일부터 일요일, 월은 로컬 달력의 첫날부터 마지막 날까지다. 기간별 합계 아래 제공자, 모델과 확인 가능한 사용 경로별 입력·출력 토큰, 캐시 읽기, 기록 건수를 표시한다. 캐시 읽기 토큰은 입력 토큰에 이미 포함되므로 두 수치를 더하지 않는다. CSV에는 합계 행 없이 모델·출처별 집계만 담는다.

현재 설정된 Claude·Codex 기록 폴더를 계속 읽고 정규화된 이력을 `$XDG_STATE_HOME/ai-mon/history.sqlite3` 또는 `~/.local/state/ai-mon/history.sqlite3`에 저장한다. 기존 7일 상태 캐시와 별도로 저장하며 자동 삭제하지 않는다. 최초 실행에서는 로컬에 남아 있는 이전 기록을 시간 순서와 관계없이 수집하고, 큰 기록은 여러 번에 나누어 처리한다. 수집 중에는 화면에 진행 상태를 표시한다. 원본이 나중에 삭제되더라도 이미 수집한 이력은 유지된다. 로그 폴더를 바꿔도 이전에 수집한 이력은 남는다.

Claude의 메시지에 기록된 모델과 Codex의 `turn_context` 모델을 사용한다. Codex의 누적 사용량이 모델 전환을 가로질러 발생한 경우 모델을 임의로 배정하지 않고 **모델 알 수 없음**으로 분류한다. Codex에서 확인 가능한 `codex_vscode`/VS Code 또는 CLI 출처는 별도로 표시하며, 근거가 없는 기록은 **출처 알 수 없음**으로 표시한다. Claude 기록에서 사용 경로를 확실히 확인할 수 없는 경우에도 출처를 추정하지 않는다.

Codex `sessions` 폴더와 같은 상위 폴더의 `archived_sessions`도 읽는다. 세션 식별자가 유지된 중복 기록은 이벤트 식별자로 중복 제거한다. 식별자가 없는 기록은 파일 경로에 의존하므로 복사·이동 시 중복될 수 있다. 이 PC에 남아 있는 CLI·VS Code 로컬 기록이 대상이다. 다른 PC, 원격 서버, WSL, 웹 또는 별도 설정 디렉터리의 기록이 자동으로 모두 포함되는 것은 아니다. 이 기능을 설치하기 전에 이미 삭제된 원본은 새 이력으로 가져오지 못한다. 기존 7일 상태 캐시만 남은 이벤트는 이력 DB에 자동 이전하지 않는다. 파일이 교체되거나 다시 작성되어 과거 누적값을 안전하게 보정할 수 없는 경우 화면에 일부 기록의 정확성을 확인하라는 안내가 표시된다.

이력 DB에는 모델·출처·사용량과 중복 제거 및 읽기 위치에 필요한 식별자가 들어간다. 프롬프트·응답 본문과 인증 정보는 저장하지 않는다. DB 파일은 일반적으로 현재 사용자만 읽을 수 있는 권한으로 새로 만든다. 이력은 용량 제한 없이 보관하므로 장기간 사용하면 DB 크기가 늘 수 있다. 최대 10,000개 집계 행까지 표시하며 그 이상인 경우 안내하고 부분 CSV 내보내기를 막는다.

`scripts/linux/test-history.sh`는 SQLite 개발 파일이 필요하다. 주·월 경계, 모델 전환의 미확인 분류, VS Code 출처, Claude 메시지 보정, 보관 파일 중복 제거, 원본 삭제 뒤 복원, CSV 수식 문자열 처리를 검사한다.

## 검증 기록

Ubuntu 24.04 가상 환경에서 코어·이력 테스트와 X11/Wayland UI 통합 테스트를 통과했다. 모의 Claude·Codex 데이터로 모델 및 VS Code 출처, 주·월 합계, 이력 창, 트레이 동작을 확인했다. 같은 크기와 수정 시각으로 교체된 파일을 감지하면 과거 이력의 정확성을 주의하도록 표시하며, 재시작 후 이어 읽기와 원본 삭제 후 보존도 시험했다. CSV 문자열의 수식 해석 방지와 파일 쓰기는 자동 테스트했고, 저장 대화상자의 실제 선택·저장은 데스크톱 환경별로 추가 확인이 필요하다.

이 PC의 Codex 기록을 별도 임시 데이터베이스로 읽었을 때 2,879건 중 2,871건에서 모델을 확인했고, 2,740건은 VS Code 출처로 분류됐다. 이 수치는 시험 시점의 로컬 파일 범위이며 전체 계정 사용량을 의미하지 않는다. 실제 Claude VS Code 기록의 출처 구분은 아직 검증하지 않았다.

Windows 버전의 동일 기능과 검증 상태는 [Windows 이력 안내](WINDOWS_HISTORY.md)를 참고한다.
